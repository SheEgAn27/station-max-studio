# История изменений

## 2.1.3 — 2026-10-25

- современный интерфейс и точный предпросмотр матрицы 25×16;
- редактор изображений и GIF;
- импорт и преобразование видео;
- произвольное время показа статичных изображений;
- рисование на экране колонки;
- единый вход через Яндекс во встроенном приватном окне;
- автоматический поиск Станции после смены Wi‑Fi;
- ползунки больше не изменяются случайно колесом мыши;
- автоматический показ фирменного логотипа после подключения;
- подготовлена переносимая публичная сборка без пользовательских данных.
- пользователь может пройти SmartCaptcha прямо во встроенном окне Яндекса;
- при отсутствии WebView2 приложение предлагает установить официальный компонент Microsoft;
- cookies встроенного окна используются в приватном режиме и не сохраняются;
- исправлена передача области cookies `.yandex.ru`, из-за которой API устройств отвечал `401`;
- окно входа закрывается только после реальной проверки токена через API устройств;
- добавлены автотесты авторизации и проверка уже собранного EXE.
