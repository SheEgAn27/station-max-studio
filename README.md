# Station Max Studio

Неофициальное приложение для управления фронтальным LED-экраном Яндекс Станции Макс с матрицей 25×16.

**Текущая версия: 2.1.3 — by SheEgAn**

Программа позволяет отправлять на экран колонки фотографии, GIF и видео, рисовать вручную и заранее видеть результат на точной сетке 25×16.

## Возможности

- преобразование JPG, PNG, GIF, WebP и других изображений в формат экрана 25×16;
- импорт MP4, MOV, AVI, MKV, WebM, M4V, MPEG и MPG;
- предпросмотр каждого пикселя до отправки;
- обрезка, масштаб, сдвиг, яркость, контраст, поворот, отражение и инверсия;
- выбор времени показа статичного изображения вплоть до технического максимума;
- рисование мышью непосредственно на матрице;
- сохранение готовых GIF и история последних файлов;
- вход по QR, через cookies или импорт авторизации из другого экземпляра программы/Home Assistant;
- автоматический поиск выбранной Станции в текущей локальной сети.

## Совместимость

- Windows 10 или Windows 11, 64-bit;
- Яндекс Станция Макс с фронтальным экраном 25×16;
- компьютер и колонка в одной локальной сети.

Другие модели Станций могут появляться в списке аккаунта, но без матрицы 25×16 не смогут показать подготовленный GIF.

## Быстрый запуск

1. Откройте раздел [Releases](../../releases/latest).
2. Скачайте `Station-Max-Studio-2.1.3-Windows-x64.zip`.
3. Распакуйте архив полностью.
4. Запустите `Station Max Studio v2.1.3.exe`.
5. При запросе брандмауэра Windows разрешите доступ только для частных сетей.
6. Откройте «Настройки», войдите через Яндекс, выберите Станцию Макс и нажмите «Найти в этой Wi‑Fi-сети».

Если Windows SmartScreen показывает предупреждение, это связано с отсутствием платного сертификата подписи. Исходный код и сценарий сборки находятся в этом репозитории.

## Подключение

### Без Home Assistant

1. ПК и Станция должны быть подключены к одному роутеру.
2. На время поиска отключите VPN, прокси и гостевую изоляцию Wi‑Fi.
3. В приложении нажмите «Войти по QR» и подтвердите вход в браузере.
4. Выберите колонку, нажмите «Найти в этой Wi‑Fi-сети», затем сохраните настройки.

#### Если Яндекс показывает «Вы не робот?»

Иногда Яндекс заменяет служебную страницу QR-входа на SmartCaptcha. Это серверное ограничение зависит от аккаунта и IP-адреса; повторные запросы из приложения его не обходят.

1. Откройте в обычном браузере `https://passport.yandex.ru/profile`, войдите в нужный аккаунт и пройдите проверку.
2. С помощью доверенного локального инструмента браузера экспортируйте cookies домена `yandex.ru` в JSON. Также подходит скопированная строка заголовка `Cookie`.
3. В Station Max Studio выберите «Войти через Cookies» и загрузите JSON или вставьте строку.
4. Приложение один раз обменяет cookies на токен Яндекса. Сами cookies на диск не записываются.

Cookies дают доступ к аккаунту: не публикуйте их, не отправляйте другим людям и удалите экспортированный JSON после успешного входа.

#### Перенос с другого ПК

На уже работающем ПК скопируйте файл `%APPDATA%\Station Max Studio\settings.json`. На новом ПК нажмите «Импорт settings.json» и выберите этот файл. Затем обязательно нажмите «Найти в сети»: при смене компьютера или Wi‑Fi локальный IP колонки определяется заново.

### Через Home Assistant

Home Assistant не обязателен. Если интеграция `AlexxIT/YandexStation` уже настроена, нажмите «Импорт из Home Assistant…» и выберите папку `config`. Приложение прочитает авторизацию из `.storage/core.config_entries`, после чего попросит выбрать колонку и найти её в локальной сети.

## Как происходит отправка

Приложение временно запускает локальный HTTP-сервер (по умолчанию порт 8765), передаёт колонке локальный URL файла и отправляет команду по совместимому локальному протоколу Станции. Проброс портов на роутере не нужен и не рекомендуется.

## Приватность и безопасность

- пароль Яндекса приложение не получает и не сохраняет;
- cookies, вставленные для альтернативного входа, используются только для получения токена и не сохраняются;
- токен, настройки и история сохраняются только локально в `%APPDATA%\Station Max Studio`;
- токены и пользовательские файлы в репозиторий и релиз не включены;
- не передавайте файл `settings.json` другим людям;
- для полного сброса удалите `%APPDATA%\Station Max Studio`.

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python .\src\station_max_studio.py
```

```powershell
.\build_release.ps1
```

## Ограничения

Это неофициальный проект, не связанный с Яндексом. После обновления прошивки или серверов Яндекса отдельные функции могут потребовать обновления приложения. Системные анимации, ответы Алисы, регулировка громкости и перезапуск колонки могут заменить пользовательское изображение раньше выбранного времени.

При разработке учитывалась открытая интеграция [AlexxIT/YandexStation](https://github.com/AlexxIT/YandexStation).
